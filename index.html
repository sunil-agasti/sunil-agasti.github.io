AI-assisted developer tooling

Claude Code skills, hooks and agents I wrote so the team's routine work runs the same way every time.

  • Skill

    git-pr

    Commit, push and open a PR in one step. Writes the change summary, keeps the ticket ID, commit subject and PR title identical, fills every section of the PR template, and refuses unsafe git operations.

  • Hook

    Format on change

    A Bash hook that runs after every file the agent edits: Prettier and ESLint fixes for TS/JS, google-java-format (AOSP) for Java — so the pre-push hook never fails.

  • Agent

    AX accessibility audit

    Runs an accessibility rule engine (90+ WCAG 2.1/2.2 AA rules plus stricter internal checks), scores each file, applies auto-fixes and uses Playwright to measure real contrast in light and dark mode. A companion review agent checks labels, headings, focus and ARIA.

#!/usr/bin/env bash
# PostToolUse: auto-format files after the agent edits them
set -uo pipefail
input="$(cat || true)"
file="$(jq -r '.tool_input.file_path // empty' <<<"$input")"
case "$file" in
  *.ts|*.tsx|*.js|*.jsx) npx prettier --write "$file"
                         npx eslint --fix "$file" ;;
  *.java) java -jar google-java-format.jar --aosp -i "$file" ;;
esac
exit 0  # never block the edit pipeline
