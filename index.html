IT-Dashboard: one portal for Mac fleet management

Architect & builder · Internal IT portal
Next.js 16React 19TypeScriptBashTailwind CSS v4npm workspacesTurbopackSSHJamfBox · EngWebTesseract.js · ZXingMakefile

A monorepo that puts six internal tools behind one sign-on. IT staff sign in once at /admin. Any employee who opens the portal without signing in lands on a Self Service page for their own Mac.

  • Self Service / Software Hub: remote install, update and uninstall over SSH. Installers come from Box or EngWeb and are checked against a pinned SHA-256 hash, a valid codesign signature and the expected Apple Team ID before a Bash installer runs them.
  • Device Management: time-limited admin rights (expiry marker on the Mac plus a launchd job that revokes them) and temporary GitHub access that also expires automatically, with every grant and removal logged.
  • Supply chain & secrets: passwords and tokens go through environment variables and stdin, never command-line arguments or logs. A scheduled check flags release files that were silently replaced.
  • Bash-first operations: make setup and make dev handle bootstrap, secrets, starting and supervising every app, and VPN-aware keep-alive hosting.

  • git-pr skill: handles commit, push and PR in one step. It writes the change summary, keeps the radar, commit subject and PR title identical, fills in every section of the repo's PR template, and refuses unsafe git operations.
  • Format-on-change hook: a Bash hook that runs after every file the agent edits. It applies Prettier and ESLint fixes to TS/JS and google-java-format (AOSP style) to Java, then checks formatting before push so the pre-push hook never fails.
  • AX accessibility agent: runs the ax CLI against 92 WCAG 2.1/2.2 AA and Apple AA+ rules. It scores each file, applies auto-fixes, and uses Playwright to check real contrast in light and dark mode. A companion review agent checks labels, headings, focus and ARIA.

#!/usr/bin/env bash
# PostToolUse: auto-format files after the agent edits them
set -uo pipefail
input="$(cat || true)"
file="$(jq -r '.tool_input.file_path // empty' <<<"$input")"
case "$file" in
  *.ts|*.tsx|*.js|*.jsx) npx prettier --write "$file"
                         npx eslint --fix "$file" ;;
  *.java) java -jar google-java-format.jar --aosp -i "$file" ;;
esac
exit 0  # never block the edit pipeline
